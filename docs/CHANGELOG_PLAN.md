# 기획 변경 비교 — v0.1 → v0.2

| 구분        | 이전 v0.1                     | 개정 v0.2                                      | 근거·이유                                                                  |
| ----------- | ----------------------------- | ---------------------------------------------- | -------------------------------------------------------------------------- |

| 자료 입력   | 새 협업 질문에 직접 답변      | 홍보문·예약폼 원문 보관·구조화 초안 확인       | 기존 운영 자료를 다시 입력하는 부담                                        |

| 예약        | 별도 관리 범위 없음           | 외부 폼 연결·수동/CSV 명단·정원·대기           | 프로필 링크와 구글폼 예약 우선 운영                                        |

| 다음 회차   | 과거 기록 열람                | 설정·메뉴·체크리스트만 복제                    | 고객·입금·환불 및 과거 마감 기한 재사용 방지                               |

유지하는 원칙: 질문 중심 입력, 다음 행동 안내, 한 회차에 자료 모으기, 법률 판단 비대체, 모바일 우선, 자동 저장, 기존 데이터 보존. 결제·전자서명·세금 신고·POS 자동 연동은 여전히 범위 밖입니다.

**이번 코드에 들어가는 범위:** 안타르티카 예제 불러오기, 별도 예제 가게, 중복 생성 방지, 두 타임 표시, 사업자·결제·조리·인원의 미확인 표현, 원문 기반 메뉴·예약·환불 메모와 체크리스트·사전 안내문. 실제 예약·입금·환불·체크인은 다음 개발 대상으로 명시했습니다.

세부 화면·엔터티·상태·계산·개발 우선순위는 [제품 설계 v0.2](PRODUCT_DESIGN.md)에 정리했습니다. 실계좌·예금주·로그인 이메일과 실제 고객 명단은 공개 예제와 기획서에 옮기지 않았습니다.
